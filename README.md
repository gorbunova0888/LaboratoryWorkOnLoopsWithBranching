# Лабораторная работа №3. Циклы с ветвлениями

**Автор:** Горбунова Анастасия  
**Вариант:** 5

## Задача

Вычислить число Гросгофа `Gr` и число Нуссельта `Nu` для серии
диаметров труб по формулам:

    Gr = g * d^3 / theta^2 * (tG - tB) / (tB + 273)
    Nu = 0.76 * Gr^0.22, если Gr <  1e9
    Nu = 0.15 * Gr^0.35, если Gr >= 1e9

## Запуск

1. Открыть `CyclesWithBranching.sln` в Visual Studio.
2. **Сборка → Пересобрать решение**.
3. **F5**, ввести данные по подсказкам.
